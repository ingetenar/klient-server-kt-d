# Sulgpalliklubi

Sulgpalliklubi projekt kliendi-serveri mudeli ja veebirakenduse tööpõhimõtete õppimiseks.

## Projekti struktuur

## Avaleht

Projekti avaleht asub failis `avalik/index.html`.
